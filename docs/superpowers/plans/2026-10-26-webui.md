# Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a light, password-protected, server-rendered web UI (port 45462) that manages the Discord webhook, webhook listen port, console UUIDs and the MAC to name camera list, replacing per-camera env vars.

**Architecture:** Settings live in a JSON file (`/config/settings.json`) behind a `SettingsStore`. Spring Boot (MVC + Thymeleaf) serves only the UI on the web UI port. The UniFi `POST /data` endpoint moves off Spring onto a separate JDK `com.sun.net.httpserver.HttpServer` on the webhook port, so the two ports are isolated by construction and the listener can be rebound at runtime without Spring Security or extra connectors. Auth is a hand-rolled session interceptor plus `spring-security-crypto` BCrypt (no full Spring Security).

**Tech Stack:** Java 17, Spring Boot 3.4.4 (`spring-boot-starter-web`, add `spring-boot-starter-thymeleaf`), `org.json` (existing), `org.springframework.security:spring-security-crypto`, `org.commonmark:commonmark:0.24.0`, JUnit 5. Build/test with `./mvnw` (no system `mvn`).

**Spec:** `docs/superpowers/specs/2026-10-26-webui-design.md` (mockup: `docs/superpowers/specs/2026-10-26-webui-mockup.html`)

## Global Constraints

- Web UI port default **45462**, overridable only by env `webui_port`; not editable in the UI.
- Webhook listener default **8080**, editable in the UI, env `port` still imported; rebinding applies without restart; refuse the save (keep old port) if the new port cannot be bound; webhook port must be 1-65535 and differ from the UI port.
- Default login `admin`/`admin`, works once, forced password change before any other page; password stored BCrypt-hashed, never plaintext.
- Discord webhook must match `https://discord\.com/api/webhooks/[0-9]+/[A-Za-z0-9_\-]+` (existing regex); MAC must match `^([0-9A-Fa-f]{2}[:-]){5}([0-9A-Fa-f]{2})$` and is normalized to uppercase colon-separated.
- Env import is one-time per value (recorded in settings); env-derived values never overwrite a value the user already has; banner lists env vars **currently set** in the container, is dismissable per page load, returns every load until the Settings toggle `showEnvReminder` is off.
- No webhook configured: app still starts; `POST /data` returns 200, logs a warning, sends nothing. Invalid env webhook is not imported.
- `/config` missing/unwritable: run on in-memory settings and show a prominent "changes will be lost on restart" warning in the UI.
- `POST /data` only on the webhook port; UI never served on it and vice versa.
- Session cookie not `Secure` by default; `Secure` when `X-Forwarded-Proto: https`. CSRF token on every UI POST. Failed login gets a small delay, no lockout.
- Container runs as `USER 99:100`. Keep image light: no JS framework or build toolchain.
- `guides/` is bundled into the image at build time; build must not fail if `guides/` is absent; Guide page then shows a friendly "guide not available" message.
- Existing tests (`ThumbnailsTest`, `WebhookClientMultipartTest`) keep passing. Code style: tabs, Allman braces, as in existing sources.

## Review Focus

- Lowercase or dash-separated MAC in env or UI (`aa-bb-cc-11-22-33`) must match the incoming UniFi device ID (Task 1, Task 2, Task 3 tests).
- Malformed or non-JSON `POST /data` body, or payload without `alarm`, must not crash the listener or return 500 to UniFi (Task 3 test).
- Duplicate MAC added in the UI should update the existing name rather than create two rows (Task 5 test).
- Unwritable `/config` or corrupt `settings.json` must not stop startup (Task 1 tests).
- Direct navigation to any UI page, or a POST without CSRF token, while logged out or mid-forced-password-change must be refused/redirected (Task 4 tests).

## File Structure

Package `com.webhookmiddleman` unless noted.

- `settings/Settings.java`: plain data holder (fields below), Jackson/org.json-free; serialized by the store.
- `settings/SettingsStore.java`: load/save/in-memory fallback, thread-safe accessors, MAC normalization.
- `settings/EnvImporter.java`: pure env to Settings import + env-var inventory for the banner.
- `WebhookProcessor.java`: payload handling extracted from `WebhookController` (no Spring annotations).
- `WebhookListener.java`: JDK `HttpServer` lifecycle (`start(int)`, `rebind(int)`, `stop()`).
- `web/AuthInterceptor.java`, `web/AuthController.java`, `web/WebConfig.java`: session auth, CSRF, login/logout/change-password, interceptor registration.
- `web/CameraController.java`, `web/SettingsController.java`, `web/GuideController.java`, `web/UiAdvice.java` (adds banner/warning model attributes to every page).
- `src/main/resources/templates/*.html`, `src/main/resources/static/app.css`.
- Modify: `Application.java` (strip env statics; bootstrap), `WebhookController.java` (delete), `pom.xml`, `dockerfile`, `README.md`, `.dockerignore`.
